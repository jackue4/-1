# 温馨庭院与毛绒居民迭代

交付：`outputs/little-bloom.html`。构建：`node work/planet-v2/build.mjs`。

## 本轮变更

- 住宅从五座减少为两座，分别放大 22% 与 16%，保留朝向菜园的入口。
- 庭院增加浅池塘、睡莲、水纹、岸石与芦苇。原有后三座房屋的施工阶段改为长椅、花箱和野餐角，保留阶段 ID、总工期与存档进度。
- 六位居民改为原创毛绒比例：垂耳兔、小熊、柯基、奶油猫、小浣熊、小鹿。使用平滑体块、短绒轮廓、柔和纤维着色、奶油色腹部、眼睛高光与项圈。
- 为住宅门廊、树干、池塘、功能建筑、石块、栅栏及移动的施工材料堆加入球面寻路和连续路径碰撞检查；动物之间加入避让。堵塞目标会投影到可站立位置。
- “动物伙伴”视角轮流近看六位居民；拖拽或切换视角退出跟随。
- 保留前轮平滑树冠与实例化植物、种田、建造、旅行和天气系统；不清空存档。

## 检查结果

- 世界与原有逻辑：21 项通过。
- 新庭院/寻路/动物检查：7 项通过，包括动态障碍搬动、实际居民持续行走与避雨，以及全部 18 块田的工作位置连通。
- 农场规则与场景：9 项通过，包括真实助手走到田边并浇水。
- 原有 DOM 与新增动物近景交互：17 项通过。
- 农场 DOM、射线选田与存档恢复：8 项通过。
- 16 组着色器编译/链接通过，包括新增 plush-fur。
- 最终 HTML 回读确认动物近景、毛绒材质、柯基、实体导航、种田 UI 及存档键均已打包，未残留模板占位符。

场景预算：644437 个三角形，148577 个投影三角形；上一轮树木版本为 649787 / 147963。草仍有 14967 根，以三段弯曲草叶降低几何开销，供动物细节使用。这里是场景几何预算，不是实际逐帧绘制数或帧率。

## 验证边界

DOM 检查使用实际 Three.js 场景、相机和射线，但 WebGLRenderer 被测试桩替代。GLSL 编译检查没有运行真实 GPU 画面。软件深度光栅预览用于确认布局与动物比例，没有完整重现透明水体、毛绒着色、实时阴影及植物着色器。

浏览器控制重试返回 `unsupported Codex auth method: apikey`，没有得到可操作的预览页面。因此本轮没有浏览器画面验收或实际帧率结论。
